  (a) Verbatim reference template — Assets/MapRenderer.Unity/Shaders/UnityLit/
      Unmodified copies of the URP Lit shader set, vendored as a diff baseline so our map shaders
      can be audited as a minimal delta against stock Lit. The ONLY changes from upstream are the
      shader name (Universal Render Pipeline/Lit → Template/UnityLit) and include paths (rewritten
      to local-relative). Reference-only; bound to no material at runtime.
      See Assets/MapRenderer.Unity/Shaders/UnityLit/README.md for provenance + refresh procedure.

        UnityLit.shader              ← Lit.shader
        LitInput.hlsl                ← LitInput.hlsl
        LitForwardPass.hlsl          ← LitForwardPass.hlsl
        LitGBufferPass.hlsl          ← LitGBufferPass.hlsl
        ShadowCasterPass.hlsl        ← ShadowCasterPass.hlsl
        DepthOnlyPass.hlsl           ← DepthOnlyPass.hlsl
        DepthNormalsPass.hlsl        ← DepthNormalsPass.hlsl
        LitDepthNormalsPass.hlsl     ← LitDepthNormalsPass.hlsl
        LitMetaPass.hlsl             ← LitMetaPass.hlsl

  (b) Editable derivatives (verbatim-plus-delta) — Assets/MapRenderer.Unity/Shaders/Map/
      Each is a mirror-copy of a URP source file plus map-specific deltas (paint + tweakable
      render-state properties, the MapVertexModify / line-extrusion hook, coverage/alpha). Each
      carries a UCL attribution header documenting its delta from upstream.

        Map/Fill/Fill.shader                 ← Lit.shader
        Map/Fill/Fill_LitInput.hlsl          ← LitInput.hlsl
        Map/Fill/Fill_LitForwardPass.hlsl    ← LitForwardPass.hlsl
        Map/Fill/Fill_LitGBufferPass.hlsl    ← LitGBufferPass.hlsl
        Map/Fill/Fill_ShadowCasterPass.hlsl  ← ShadowCasterPass.hlsl
        Map/Fill/Fill_DepthOnlyPass.hlsl     ← DepthOnlyPass.hlsl
        Map/Fill/Fill_DepthNormalsPass.hlsl  ← LitDepthNormalsPass.hlsl
        Map/Line/Line.shader                 ← Lit.shader
        Map/Line/Line_LitInput.hlsl          ← LitInput.hlsl
        Map/Line/Line_LitForwardPass.hlsl    ← LitForwardPass.hlsl
        Map/Line/Line_LitGBufferPass.hlsl    ← LitGBufferPass.hlsl
        Map/Line/Line_ShadowCasterPass.hlsl  ← ShadowCasterPass.hlsl
        Map/Line/Line_DepthOnlyPass.hlsl     ← DepthOnlyPass.hlsl
        Map/Line/Line_DepthNormalsPass.hlsl  ← LitDepthNormalsPass.hlsl
        Common/LitInput.Template.hlsl        ← LitInput.hlsl (Map-flavoured skeleton template; S66)

  (c) Bespoke map helpers — original clean-room work, NOT Unity-derived; listed here only so the
      shader tree's provenance is unambiguous:
        Map/Line/Line_VertexExtrude.hlsl   — world-space ribbon extrusion + line coverage
        Map/Fill/Fill_VertexModify.hlsl    — fill vertex hook

Fill triangulation is a clean-room implementation of the ear-clipping algorithm. The Mapbox
"earcut" project (ISC) was consulted only as an algorithm reference; no source was copied.

DATA / TEST FIXTURES
--------------------
Assets/Fixtures/sample-tile.bytes
  A single Mapbox Vector Tile (z0/x0/y0) from the MapLibre "demotiles" dataset.
  Underlying geometry: Natural Earth — public domain (no attribution required).
  Sources: https://demotiles.maplibre.org/  •  https://www.naturalearthdata.com/
  Bundled as an offline, deterministic test fixture.

Assets/Fixtures/maplibre-demo-style.json
  A MapLibre GL JS style document describing the "demotiles" basemap.
  Committed as the demo style for MapDemo.unity (S40) and as a test fixture
  for the styled-fill pipeline (MapViewStyledFillTests).
  Underlying data: Natural Earth — public domain (no attribution required).
  Source: https://demotiles.maplibre.org/style.json
  License: the style JSON itself is considered data/configuration, not a
  copyrighted work under MapLibre's Apache-2.0 license (which applies to
  MapLibre GL JS source code, not the style schemas or Natural Earth data).

Assets/Fixtures/glyphs/NotoSansRegular/*.pbf.bytes
  (0-255.pbf.bytes, 1536-1791.pbf.bytes, 64256-64511.pbf.bytes, 65024-65279.pbf.bytes)
  Pre-baked SDF glyph-bitmap ranges for the "Noto Sans Regular, ..." font stack, fetched from
  MapLibre's public "demotiles" glyph endpoint (S18 — glyph-atlas/SDF text rendering).
  Underlying font: Noto (multiple faces in the stack) — SIL Open Font License 1.1 (OFL-1.1).
  Fetch endpoint: https://demotiles.maplibre.org/font/{fontstack}/{range}.pbf
  Bundled as an offline, deterministic test fixture (glyph-PBF decode: GlyphPbfDecodeTests / T2).
  License: the OFL applies to the Noto font data the SDF bitmaps are derived from; the OFL text
  is available at https://scripts.sil.org/OFL — no copyleft on our own code (font data is not
  linked/derivative in the copyleft sense; it is bundled as data, per OFL §1/§2 permitted use).

LIVE NETWORK ENDPOINT (runtime only)
-------------------------------------
https://demotiles.maplibre.org/tiles/{z}/{x}/{y}.pbf
  The MapLibre demotiles vector tile endpoint used by MapViewBootstrap at runtime.
  Tiles are NOT bundled in this repo. Fetched over HTTP only when the MapDemo.unity
  scene is run in Play mode. This is a free public endpoint.
  Underlying geometry: Natural Earth — public domain (no attribution required).
  Endpoint maintained by: MapLibre contributors.
  Subject to the endpoint's terms of service and fair-use policy.
