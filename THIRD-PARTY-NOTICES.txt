Unity Universal Render Pipeline (URP) editor ShaderGUI — partial derivative work
  The following file in Assets/MapRenderer.Unity/Editor/ replicates protected override bodies
  from a Unity URP editor source file (com.unity.render-pipelines.universal version 17.5.0):

    MapLitShaderGUI.cs        ← derived from LitShader.cs (Editor/ShaderGUI/Shaders/LitShader.cs)

  Scope of the derivation: only the bodies of DrawSurfaceOptions, DrawSurfaceInputs, and
  DrawAdvancedOptions replicate URP LitShader's protected override expressions (URP exposes no
  hook to reach them without copying). The rest of the file (the Map Paint foldout and wiring)

  The MapLibre demotiles vector tile endpoint used by MapViewBootstrap at runtime.
  Tiles are NOT bundled in this repo. Fetched over HTTP only when the MapDemo.unity
  scene is run in Play mode. This is a free public endpoint.
